# Personal Expense Tracker

A simple Python program that calculates your remaining balance after a purchase. This project was created to practice fundamental Python concepts, including functions, loops, conditional statements, and user input.

## Features

- Enter an initial balance.
- Enter the price of a purchase.
- Calculate the remaining balance.
- Validate that balances and purchase prices are not negative.
- Display different messages depending on the remaining balance.

## Built With

- **Python 3**
- Built-in Python functions and features

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the Python program.

## Example

```text
How much money do you have: $100
What was the price of the item(s): $25
Your remaining balance is $75.0.
```
